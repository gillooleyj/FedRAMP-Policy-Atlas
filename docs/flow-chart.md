# Flow chart alternative

The explorer now offers 3D Map, Flow chart and Table, in that order. A separate presentation state preserves the Everything/FedRAMP 20x dataset scope when switching views. Selected entity, class and relationship filters, and connection depth remain shared. URLs encode `mode=flow` or `mode=table`; existing `view=table` URLs still open the table.

The visual direction comes from the user's supplied dark policy-map screenshot: rounded colored cards, vertical accent bars, a dotted canvas, curved connections, a compact legend and a reset control. The implementation retains the atlas's established FedRAMP blue, KSI pink and NIST amber. Its full-width unselected overview shows 13 actual entities and 12 existing relationships across representative branches. It is explicitly labelled an overview of selected branches. The reference's legislation, OMB policy, additional NIST publications and baselines are not new source data and were not imported.

Cards open the shared source inspector. Existing verified connectors retain their original direction and provenance; clicking one, or focusing it and pressing Enter/Space, selects its source endpoint and opens the exact evidence record. Relation labels appear on hover/focus or for the inspected edge, keeping the default chart quieter. Ports without displayed incoming/outgoing relationships are hidden. Connections cannot be edited or created through the chart.

Search opens any available entity. The existing one/two/three-level control supplies the same filtered, verified neighborhood as the 3D map. Charts initially display at most 60 entities with visible totals and a Show 60 more action; selection and the inspected edge endpoints receive priority. Every connector shown has two displayed endpoints, and no shortcut or aggregate edge is fabricated. Reset clears the chart selection and returns to the overview while keeping user filters. Show chart overview is also available in the inspector.

React Flow supplies pan, pinch zoom, zoom/fit controls, keyboard focus and SVG connectors. Dagre computes deterministic left-to-right positions; large fan-outs wrap into short columns to avoid a tall, unreadable list. Layout indicates connectivity rather than legal authority or time. Mobile opens at a readable minimum zoom and supports panning; Fit can show the full diagram at a smaller scale. Reduced-motion settings suppress programmatic camera animation.

The renderer and layout library load only when Flow chart is opened; the existing Three.js main-bundle warning remains. No new service, account, API, data ingestion or paid integration is required. Source coverage remains 1,676 entities, 3,696 verified relationships and 558 published KSI mappings, with existing pinned revisions and applicability.

Validation artifacts: `flow-browser-results.json`, `screenshots/flow-overview-desktop.png`, `screenshots/flow-overview-panel.png`, `screenshots/flow-ksi-desktop.png`, and `screenshots/flow-mobile.png`. Model tests cover authoritative identities, exact endpoints/provenance, filtered and isolated states, capped expansion, inspected-edge priority, deterministic non-overlapping layouts, wrapped fan-outs, cycles and parallel relationships. Browser checks cover all three presentations, pointer and keyboard evidence, pan/zoom/reset, depth expansion, filters, scope persistence, URL reload, legacy table links and mobile overflow.

Known limits: the default overview is representative, not a complete legal/policy hierarchy. Large expanded neighborhoods can remain dense and require panning/zooming or the table. Physical-device touch and formal assistive-technology audits remain future validation. Labeling research is recorded in `backlog.md`.
