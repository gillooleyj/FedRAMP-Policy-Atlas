# Flow chart alternative

The explorer now offers 3D Map, Flow chart and Table, in that order. A separate presentation state preserves the Everything/FedRAMP 20x dataset scope when switching views. Selected entity, class and relationship filters, and connection depth remain shared. URLs encode `mode=flow` or `mode=table`; existing `view=table` URLs still open the table.

The visual direction comes from the user's supplied dark policy-map screenshot: rounded colored cards, vertical accent bars, a dotted canvas, curved connections, a compact legend and a reset control. The implementation retains the atlas's established FedRAMP blue, KSI pink and NIST amber. The default full FedRAMP scope now includes all 459 imported FedRAMP entities and 1,922 internal verified relationships, initially capped at 60 displayed cards. Explore branch covers every ruleset, KSI theme, class and definition. Include mapped NIST controls adds only actual published endpoints and their containment ancestors. The old 13-entity, 12-edge example remains an explicitly named menu option. The reference's legislation, OMB policy, additional NIST publications and baselines are not new source data and were not imported.

Cards open the shared source inspector. Existing verified connectors retain their original direction and provenance; clicking one, or focusing it and pressing Enter/Space, selects its source endpoint and opens the exact evidence record. Relation labels appear on hover/focus or for the inspected edge, keeping the default chart quieter. Ports without displayed incoming/outgoing relationships are hidden. Connections cannot be edited or created through the chart.

Search opens any available entity. The existing one/two/three-level control supplies the same filtered, verified neighborhood as the 3D map. Charts initially display at most 60 entities with visible totals and Show 60 more and Show all actions; selection and the inspected edge endpoints receive priority. Every connector shown has two displayed endpoints, and no shortcut or aggregate edge is fabricated. Reset clears the chart selection and returns to the chosen branch while keeping user filters and mapped-control preference. Show chart overview is also available in the inspector.

React Flow supplies pan, pinch zoom, zoom/fit controls, keyboard focus and SVG connectors. Dagre computes the starting branch layout from containment where present. Existing card positions are then anchored as selections reveal new neighbors; new cards occupy unused slots. Branch layout caches persist across presentation changes, with a bounded recent-scope cache. Non-containment connections keep their original endpoints and direction, so a class stays on the left even when applicability arrows point into it. large fan-outs wrap into short columns to avoid a tall, unreadable list. Layout indicates connectivity rather than legal authority or time. Large unselected branches open on their starting columns instead of fitting every card into unreadable text. Mobile opens at a readable minimum zoom and supports panning; Fit can show the full diagram at a smaller scale. Reduced-motion settings suppress programmatic camera animation.

The renderer and layout library load only when Flow chart is opened; the existing Three.js main-bundle warning remains. No new service, account, API, data ingestion or paid integration is required. Source coverage remains 1,676 entities, 3,696 verified relationships and 558 published KSI mappings, with existing pinned revisions and applicability.

Browser checks cover all three presentations, pointer and keyboard evidence, pan/zoom/reset, depth expansion, filters, scope persistence, URL reload, legacy table links and mobile overflow.

Known limits: the full FedRAMP scope is the complete imported Consolidated Rules dataset, not a complete legal/policy hierarchy. Large expanded neighborhoods can remain dense and require panning/zooming or the table. Physical-device touch and formal assistive-technology audits remain future validation. Labeling research is recorded in `backlog.md`.

The legal/policy ingestion sequence is in `policy-source-roadmap.md`.

The shared Back/Up/Overview toolbar removes the need to close the inspector to return. Back and native browser history restore selection, filters, branch, expansion limit and saved viewport. Up/breadcrumbs follow only verified containment; classes have no fabricated parent. Selecting a card centers it at readable zoom instead of automatically fitting a potentially huge neighborhood. A surface ResizeObserver keeps the selected card visible when switching between desktop and mobile widths. Explicit Fit still provides a whole-diagram overview.
