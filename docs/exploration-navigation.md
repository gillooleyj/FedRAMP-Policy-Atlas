# Regions, group discovery and connection depth

The unchanged starting view labels only FedRAMP and NIST 800-53. The next level shows Classes, Families, Rulesets, KSI themes and Definitions. These are display-only navigation regions at the centroids of visible members; they are not imported entities and do not create verified containment edges. Clicking Classes fits its visible members and shows the real individual class labels. Regions respect current layer, class and framework filters.

Zoom progression is sources → regions → groups → details. Global entry thresholds are 84%, 58% and 32% of the responsive starting camera distance; return thresholds are 94%, 68% and 40%. A region visit uses its own fitted scale: groups initially, details below 65%, returning to groups above 78%. Classes retain class labels because there is no deeper class hierarchy; Definitions show the actual definitions. Zooming out beyond 160% of the region fit returns to global navigation. Back preserves region context, and Fit all / Reset leave it. Reduced motion skips travel animation.

At group/detail levels, unselected labels rank by proximity to the screen center, with stable ID tie-breaking and collision avoidance. Hover does not reprioritize them. Limits remain ten groups/eighteen details on desktop and five/eight on narrow maps. All five region labels fit the tested initial desktop and mobile views. In other camera positions labels can be outside the viewport; the Explore groups menu provides a complete alphabetical directory of all filtered groups and definitions regardless of label visibility. Selecting a group visits its real node and inspector. The menu remains usable while another entity is selected.

Connection levels defaults to one and supports two or three. A breadth-first search finds shortest distances over verified edges in either direction. Input nodes already respect enabled layers, framework view and certification-class filtering, and input edges already respect relationship type and class applicability. Hidden nodes cannot serve as bridges. Edge direction, type, source revision and provenance are preserved. The traversal emits only existing edges explored before the chosen boundary; it adds no inferred edge between indirectly connected nodes. Cycles and parallel edges do not duplicate node counts. An isolated visible selection remains at distance zero.

Depth changes fit the camera to all reached nodes; Focus neighborhood also uses this scope. Counts show additional nodes at each distance, excluding the selected node. Points/lines at farther distances are dimmer. Labels prioritize the selection, then closer connection levels, within the normal selection label limit. The relationship chips explicitly describe direct connection types; the inspector continues to show the selected entity's immediate source-backed relationships. Select an intermediate node to inspect its next links. All links deliberately overrides edge isolation, with an explanatory note beside the depth control.

The chosen depth persists in the URL with the selected entity and filters. A class filter can remove all NIST mappings because entries without explicit class applicability do not satisfy that filter; traversal does not silently restore them. Source coverage and revisions are unchanged: 1,676 entities, 3,696 verified relationships and 558 published mappings.

Validation includes shortest paths, cycles, parallel edges, isolated/hidden roots, excluded bridges, candidate edges, exact edge identity, real KSI expansion, applicability filters, and presentation-only region aggregation. Browser checks compare displayed counts and edges with independently expanded source data; exercise Classes travel, Back, all 51 group destinations, selected-region navigation, depth changes, focus, filters, URL reload and mobile layout. Local production checks use the GitHub Pages project path. Physical-device usability and unrestricted live-site browser verification are not claimed.
